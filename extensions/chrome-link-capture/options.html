Save to HII

Captures are saved locally through the native host com.hii.save_to_hii, which calls hii info ingest-web.

Run node scripts/hii-chrome-native-host-install.mjs from the HII checkout, then register the generated native-host manifest with Chrome for this unpacked extension.

Page indexing

When enabled, HII saves the visible text of ordinary pages as local, searchable versions. Private windows, sign-in and payment pages, form values, and browser-internal pages are excluded. Only new browsing after enabling is captured.
