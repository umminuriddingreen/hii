HII CompanionChrome setup

Connect the local runtime

The companion sends only captures you explicitly save to HII on this computer.

  1. Install HII and run hii login if you want explicit account handoff.
  2. Register com.hii.save_to_hii for this extension ID.
  3. Restart Chrome, then check the connection below.

Local browser library

Choose each source separately. Everything is off until you enable it, and nothing is read until you press Import. Permissions can be removed here at any time.


      


      

        
Hard exclusions

        
Chrome does not expose saved passwords to extensions, so HII cannot read them. HII also never requests cookies and does not read session tokens, form values, incognito tabs, browser-internal pages, or sign-in and payment pages. Imported browser data stays local. Sharing one manually saved page with your HII account remains a separate, default-off action.

        
Removing a permission stops future reads. Previously imported local records remain in HII until you remove them there.
