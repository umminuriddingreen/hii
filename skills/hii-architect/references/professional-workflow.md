# Professional Architectural Workflow

## Phase Discipline

Label every project and artifact with one phase: `discovery`, `concept`, `schematic`, `design-development`, `permit`, `construction`, or `record`.

Do not imply a later phase through graphic polish. A concept sheet can look professional while remaining clearly marked `NOT FOR CONSTRUCTION`.

## Project Brief

Capture location, ownership/authorization boundary, project type, users, program, target area, budget basis, schedule, phasing, performance goals, revenue/community model, design character, known constraints, and decisions needed.

Convert prose into measurable criteria. Give each criterion an ID, weight, metric, target, evidence basis, and status.

## Site And Existing Conditions

Distinguish surveyed facts, public parcel/GIS data, listing or marketing data, remote observations, assumed dimensions, and proposed geometry. Preserve CRS for geospatial data and a local project frame for building geometry. Never present listing dimensions as a survey.

## Options

Create options that differ in organizing idea, not styling alone. Record concept, parameters, lineage, program fit, entitlement implications, plan/section logic, structural/system concept, environmental strategy, cost/phasing assumptions, risks, and scored criteria.

Reject options violating hard constraints. Rank remaining options using normalized weighted criteria, then explain which assumptions could change the recommendation.

## Coordination Pass

Review site, program, plan, section, structure, systems, envelope, construction, cost, and experience at phase-appropriate resolution. Create issues rather than silently resolving uncertainty. Give each issue an owner and next verification action.

## Review Boundary

Require qualified review for jurisdictional interpretation, stamped documents, structure, civil/geotechnical work, fire/life safety, energy compliance, accessibility scope, waterproofing-critical details, hazardous materials, legal/financial offerings, leases, and construction commitments.

The agent may prepare calculations and evidence, but must not impersonate licensure or certify compliance.
