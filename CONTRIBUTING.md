# Contributing to HII

First-party HII code is licensed under Apache 2.0. Retain applicable copyright and attribution notices; third-party components keep their own licenses. See LICENSE and NOTICE.

Build the CLI with `cargo build -p hii-cli`. Keep changes focused, explain their behavior, and report the checks you ran. Never submit credentials, personal records, runtime state, or generated build output.

Substantial contributions currently refer to the draft contributor agreement in CLA.md. Do not treat the draft as an executed agreement.
