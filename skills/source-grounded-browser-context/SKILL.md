# Source Grounded Browser Context

1. Read the current HII context map and name the exact claim that needs evidence.
2. Prefer existing local evidence, then primary or official sources. Use the HII-owned browser so navigation remains visible and steerable.
3. Record compact source cards: title, canonical URL, observed-at time, source class, supported claim, content hash, and short redacted extract.
4. Attach cards to the active objective and workspace as observations. Keep raw page text with the browser capture; do not inject a blind full-history dump.
5. Deduplicate by canonical URL and content hash. Mark unavailable, conflicting, stale, assumed, inferred, or illustrative evidence explicitly.
6. Build the smallest relevant context capsule and preserve links to the exact captures.
7. Before an external or consequential action, expose sources, uncertainty, and the proposed action for user steering.
8. Finish with outcome, verification, proof references, risk, and next action.

## Authority

- Read public sources and write local HII source cards.
- Do not publish, purchase, upload private context, or widen access.

## Proof

- Source cards contain URL, timestamp, class, hash, and claim linkage.
- Relevant HII browser and CLI checks pass.
