## Offer

> receipt. Founder-led. No general feature tour.

## Contact protocol

For each opportunity:

1. Open with the public job or problem that made the person relevant.
2. State that you are the founder.
3. Ask for one real job, not product feedback.
4. Do not ask them to install anything before the job and data boundary are
   mutually clear.
5. Record the response verbatim only in a private founder note; summarize the
   learning here without private details.
6. After delivery, ask:
   - What would you have done without HII?
   - Which part increased or decreased trust?
   - Would you use the same workflow again within seven days?
   - What would you pay to have this set up and maintained?

## Decision rule

Continue the narrow founder pilot if at least three of five participants complete
a first win and at least two return for a second use within seven days.

Change the job or segment if people engage with the demo but cannot name a job.

Change the trust/onboarding design if they name jobs but refuse the context
boundary.

Do not expand the platform because a launch post receives attention.
